# Rule justifications

Each rule maps to evidence claims and authoritative safety/legal sources that support, limit or block its outcome.

Required: rule ID/version, question IDs, activation conditions, missing-data behavior, safety exclusions, escalation conditions, evidence claim IDs, source IDs, population/context, dose constraints, reviewer, review date and change history.

Recommendation rules cannot override safety blocks. Rules lacking adequate evidence remain draft/review-required. Preserve historical versions so prior decisions remain explainable.
