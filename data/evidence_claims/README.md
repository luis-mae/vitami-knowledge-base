# Evidence claims

Store atomic, context-specific scientific claims here. One claim describes one outcome in a defined population and context; do not assign a single evidence rating to an ingredient as a whole.

Required fields: stable claim ID, ingredient ID, exact claim, population, preparation/form, dose and duration context, outcome, source IDs, certainty, limitations, review status, reviewer and date.

Lifecycle: draft → evidence review → safety review → approved → active → superseded.

Claims without traceable sources remain draft. Symptoms alone do not prove nutrient deficiency. A studied dose does not become an individualized recommendation without a separate reviewed rule and sufficient user context.
